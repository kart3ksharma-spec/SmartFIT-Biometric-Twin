# SmartFIT: Biometric Digital Twin Architecture for Preventive Health & Caloric Optimization

SmartFIT is an explainable, multi-signal Machine Learning system that models human physiology into a dynamic software "Digital Twin" using wearable sensor telemetry. Rather than acting as a passive historical logger, SmartFIT pairs prospective caloric burn regression and activity classification with clinical safety guardrails (ACWR overtraining detection and elevated heart rate strain warnings) and an interactive What-If simulation suite.
